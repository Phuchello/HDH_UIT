3. ĐÁP ÁN CHI TIẾT ĐỀ THI MÔ PHỎNG CUỐI KỲ SỐ 01

PHẦN 1: TRẮC NGHIỆM

  • Câu 1: C — Điều kiện đúng là "No Preemption" (Không tước đoạt). "Tước đoạt" là biện pháp triệt tiêu Deadlock.
  • Câu 2: A — Page size $4KB = 2^{12} \Rightarrow d = 12$ bits. Tổng 16 bits $\Rightarrow p = 16 - 12 = 4$ bits.
  • Câu 3: C — Chỉ có FIFO mắc Nghịch lý Belady. LRU và OPT là Stack Algorithms nên không bao giờ bị.

PHẦN 2: LỜI GIẢI CÂU 4 (ĐỒNG BỘ SEMAPHORE)

  1. a) Chứng minh $X$ có thể vượt quá 20:
    Giả sử $X = 19$. $P_1$ chạy `X = X + 1` (đã tính xong $X=20$ trong thanh ghi nhưng chưa kiểm tra `if`). $P_2$ nhảy vào chạy `X = X + 1` làm $X$ thành $21$. Sau đó $P_1$ mới kiểm tra `if (X == 20)` $\rightarrow$ sai vì $X$ đã là $21$ $\rightarrow X$ không được gán lại về $0$ và tiếp tục tăng vượt quá $20$.
  2. b) Sửa bằng Semaphore:
    Khai báo Mutex Semaphore `mutex = 1` để đảm bảo độc quyền truy xuất đoạn code kiểm tra và tăng $X$: 
    semaphore mutex = 1;

// Trong mỗi tiến trình:
do {
    wait(mutex);
    X = X + 1;
    if (X == 20) X = 0;
    signal(mutex);
} while (TRUE);

PHẦN 3: LỜI GIẢI CÂU 5 (BANKER'S ALGORITHM)

  1. a) Ma trận $Need = Max - Allocation$:
    $Need_0 = (7,4,3)$, $Need_1 = (1,2,2)$, $Need_2 = (6,0,0)$, $Need_3 = (0,1,1)$, $Need_4 = (4,3,1)$.
  2. Chạy Thuật toán An toàn ($Work = 3, 3, 2$):
    - $Need_1 (1,2,2) \le Work (3,3,2) \Rightarrow P_1$ xong! $Work = Work + Alloc_1 = (3,3,2) + (2,0,0) = (5,3,2)$.
    - $Need_3 (0,1,1) \le Work (5,3,2) \Rightarrow P_3$ xong! $Work = Work + Alloc_3 = (5,3,2) + (2,1,1) = (7,4,3)$.

5. ĐÁP ÁN CHI TIẾT ĐỀ THI MÔ PHỎNG CUỐI KỲ SỐ 02

PHẦN 1: ĐÁP ÁN TRẮC NGHIỆM

  • Câu 1: B — $EAT = t_{TLB} + (2 - \alpha) t_{RAM} = 20 + (2 - 0.8) \times 100 = 20 + 120 = 140$ ns.
  • Câu 2: B — Đúng định nghĩa điều kiện Progress theo Silberschatz/UIT.
  • Câu 3: A — Safe State đảm bảo tồn tại ít nhất 1 Safe Sequence $\Rightarrow$ chắc chắn KHÔNG bị Deadlock.

PHẦN 2: LỜI GIẢI CÂU 4 (PRODUCER - CONSUMER SEMAPHORES)

  1. Khai báo & Khởi tạo Semaphore: 
    semaphore mutex = 1; // Độc quyền truy xuất Buffer
semaphore empty = N; // Đếm số ô trống (ban đầu N = 5)
semaphore full = 0;  // Đếm số ô có dữ liệu (ban đầu 0)
  2. Mã nguồn Tiến trình Producer: 
    void producer() {
    while (true) {
        item = produce_item();
        wait(empty); // Chờ có ô trống (empty > 0)
        wait(mutex); // Khóa Critical Section
        
        insert_item(item); // Đưa item vào Buffer
        
        signal(mutex); // Mở khóa CS
        signal(full);  // Tăng số ô có dữ liệu
    }
}
  3. Mã nguồn Tiến trình Consumer: 
    void consumer() {
    while (true) {
        wait(full);  // Chờ có dữ liệu (full > 0)
        wait(mutex); // Khóa Critical Section
        
        item = remove_item(); // Lấy item ra khỏi Buffer
        
        signal(mutex); // Mở khóa CS
        signal(empty); // Tăng số ô trống
        consume_item(item);
    }
}

PHẦN 3: LỜI GIẢI CÂU 5 (BỘ NHỚ & ÁNH XẠ ĐỊA CHỈ)

  1. a) Tính số bit và số mục Bảng trang:
    - Page size $4KB = 2^{12}$ bytes $\Rightarrow$ Số bit offset $d = 12$ bits.
    - Tổng số bit địa chỉ ảo = 32 bits $\Rightarrow$ Số bit chỉ số trang $p = 32 - 12 = 20$ bits.
    - Số mục trong Bảng trang = $2^{20} = 1,048,576$ trang ($\approx 1$ triệu mục).
  2. b) Tách địa chỉ ảo $V = 16390$ và tính Địa chỉ vật lý:
    - Chỉ số trang $p = \lfloor 16390 / 4096 \rfloor = 4$.
    - Offset $d = 16390 \pmod{4096} = 16390 - 4 \times 4096 = 16390 - 16384 = 6$.
    - Địa chỉ vật lý khi $f = 5$: $\text{Physical} = f \times \text{Page\_Size} + d = 5 \times 4096 + 6 = 20480 + 6 = 20486$.
