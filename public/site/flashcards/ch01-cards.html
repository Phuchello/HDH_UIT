Mặt trước (Câu hỏi): Mode bit trong CPU mang giá trị gì ở User Mode và Kernel Mode?
💡 Gợi ý: Gợi ý: Giá trị 0 thường biểu thị mức quyền lực cao nhất.
📖 Lời giải hoàn chỉnh:
- Kernel Mode (Supervisor / Privileged): Mode bit = 0 - User Mode (Không đặc quyền): Mode bit = 1

💡 Gợi ý: Gợi ý: Xét về tốc độ, kích thước và chi phí kinh tế.
📖 Lời giải hoàn chỉnh:
1. Tốc độ truy xuất (Access Speed) 2. Dung lượng lưu trữ (Capacity) 3. Giá thành trên một bit (Cost per bit)

Active RecallM0
Mặt trước (Câu hỏi): Mục tiêu thiết kế tối thượng của Hệ thống Đa chương (Multiprogramming) là gì?
💡 Gợi ý: Gợi ý: Tận dụng thời gian CPU khi tiến trình phải chờ I/O.
📖 Lời giải hoàn chỉnh:
Tối đa hóa hiệu suất khai thác CPU (Maximize CPU Utilization) bằng cách luôn duy trì một tiến trình sẵn sàng chạy trên CPU khi tiến trình khác chờ thao tác vào/ra (I/O).

Active RecallM0
Mặt trước (Câu hỏi): Bẫy ngắt (Trap) khác Ngắt phần cứng (Hardware Interrupt) ở điểm cốt lõi nào?
💡 Gợi ý: Gợi ý: Nguồn gốc phát sinh tín hiệu là từ bên trong CPU hay từ thiết bị ngoại vi.
📖 Lời giải hoàn chỉnh:
- Trap (Software Interrupt): Tín hiệu đồng bộ do chính CPU sinh ra khi gặp lỗi lệnh (chia 0, segfault) hoặc do tiến trình gọi System Call. - Hardware Interrupt: Tín hiệu bất đồng bộ do thiết bị phần cứng ngoại vi (bàn phím, đĩa cứng, card mạng) gửi đến CPU qua bus hệ thống.
